# Documentation

These files are the upstream source for the published documentation site:

**<https://phoenixaidocsanywhere.vercel.app/Anywhere/>**

The site is built by [phoenixai-anywhere-docs](https://github.com/CelerData/phoenixai-anywhere-docs),
which imports this directory verbatim. Read the docs there — the rendering, search, and
navigation are much better than browsing raw markdown.

## Layout

The tree follows [Diátaxis](https://diataxis.fr/): four sections, one per reader need.

| Directory | Reader need | Contains |
| --- | --- | --- |
| [`tutorials/`](./tutorials) | *"Teach me."* | End-to-end lessons for newcomers. Start-to-finish, one happy path, no options. |
| [`how-to/`](./how-to) | *"Help me do this."* | Task recipes for someone who already knows what they want. Grouped by activity: `install/`, `configure/`, `scale/`, `operate/`, `develop/`, `integration/`. |
| [`explanation/`](./explanation) | *"Help me understand."* | Why the operator behaves as it does. Background, design, constraints. No instructions. |
| [`reference/`](./reference) | *"Tell me the details."* | Look-up material: CRD API, Helm charts, RBAC rules, storage classes, log paths. |

`zh/` holds the original Chinese documents. They are **not** published — the importer
skips them.

## Adding a page

1. Decide which of the four sections it belongs to. If a draft mixes types — a concept
   preamble followed by a procedure — that is a signal to split it into two pages that
   link to each other, not to pick the closest section.
2. Add frontmatter. `title`, `sidebar_label`, `sidebar_position`, and `description` are
   all expected:

   ```markdown
   ---
   title: Mount a persistent volume
   sidebar_label: Mount a persistent volume
   sidebar_position: 1
   description: Give FE metadata and BE data durable storage.
   ---

   # Mount a persistent volume
   ```

   The sidebar is generated from the filesystem, so `sidebar_position` is what orders
   pages within a section and `_category_.json` is what orders and labels the sections
   themselves. A page with no frontmatter gets a sidebar label scraped from its first
   heading, which is rarely what you want.
3. Use lowercase-kebab-case filenames. Don't suffix them with `_howto` — the directory
   already says what kind of document it is.
4. Link to other pages with relative paths that include the `.md` extension.
5. Run `../scripts/check-doc-links.sh` before you commit.

## Generated files

`reference/api.md` is the CRD API reference, generated by `gen-crd-api-reference-docs`
from the operator source. Do not hand-edit it. It is raw HTML rather than markdown, so
the site publishes it as a standalone page at `/api/` rather than as a normal doc.
