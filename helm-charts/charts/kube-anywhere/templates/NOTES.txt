{{- $adminSecret := default "anywhere-admin" .Values.anywhere.admin.existingSecret }}
Anywhere Console accounts live in the Secret "{{ $adminSecret }}" (key = username, value = password).
{{- if and (not .Values.anywhere.admin.existingSecret) (not .Values.anywhere.admin.users) }}
A single "admin" account was generated with a random password. Retrieve it with:

  kubectl -n {{ .Release.Namespace }} get secret {{ $adminSecret }} -o jsonpath='{.data.admin}' | base64 -d; echo

NOTE: this default relies on `helm lookup` and must not be used with GitOps/ArgoCD or
`helm template` pipelines (each sync would re-randomize the password) — set
anywhere.admin.users or anywhere.admin.existingSecret there instead.
{{- end }}

username and password.
